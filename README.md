# 楽曲情報DBエディタ

楽曲情報データベースを編集するためのWindows向けツールです。

標準形式として **Karaoke Video DataBase (`.kvbd`)** を使用します。  
ゆかりスターの `.ylexa` 形式にも対応しており、既存DBの読み込みや互換形式での保存が可能です。

## 🔰 はじめて使う場合：DBを1から作る

初めてこのツールを使って、楽曲情報DBを新しく作る場合は、次の順番で進めればOKです。

### 1. 初回起動時に「ID接頭文字」を決める

初回起動時に、これから新しく登録するデータへ付ける **ID接頭文字** の設定画面が表示されます。

ID接頭文字は、曲・人物・タイアップなどのIDを他のDBと区別するための文字列です。  
ここで設定した文字列をもとに、たとえば次のようなIDが自動生成されます。

```text
設定した接頭文字_S_1    ← 曲
設定した接頭文字_P_1    ← 人物
設定した接頭文字_PR_1   ← 別名義・人物関係
```

通常は、自分や自分のDBを区別しやすい名前を1つ決めれば大丈夫です。  
あとから［ツール］→［設定］で変更できますが、すでに登録済みのIDは変更されません。


起動直後は、`.kvbd` / `.ylexa` ファイルをメイン画面へ**ドラッグ＆ドロップ**して開くこともできます。

### 2. ［ファイル］→［DB新規作成...］を選ぶ

メニューから **［ファイル］→［DB新規作成...］** を選びます。

新しく作るDBは、このツールの標準形式である **Karaoke Video DataBase (`.kvbd`)** で作成されます。

### 3. DBの名前と保存場所を決める

保存ダイアログが表示されたら、DBのファイル名と保存場所を決めます。

たとえば、

```text
自分用カラオケDB.kvbd
```

のような分かりやすい名前がおすすめです。

### 4. DBへデータを入力する

DBを作成したら、画面上部の各タブからデータを登録していきます。

まず **人物・タイアップ・シリーズ・タグ・メーカー** などを登録し、その後で曲を登録すると関連情報を選びやすくなります。  
1件ずつ登録する場合は、各タブの **［追加］** を使用します。

### 既存データを大量に修正する場合

既存データをまとめて直す場合は、**Excel書き出し → Excelで編集 → Excel取り込み**がおすすめです。
再取り込み時はIDを基準に比較し、正規化後に差分がない行は更新しません。

### たくさんのデータを登録する場合

複数の項目をまとめて登録したい場合は、1件ずつ入力するより次の方法がおすすめです。

- **［一括追加］**  
  表形式のデータをまとめて貼り付けて登録できます。人物などの関連データが存在するか確認し、必要に応じて新規登録する機能も利用できます。

- **［新規入力テンプレート］→ Excel取り込み**  
  Excelで大量のデータを編集したい場合に向いています。テンプレートへ入力したあと、［Excel取り込み］からDBへ反映できます。

最初は数件を通常の［追加］で登録してDBの構造を確認し、件数が多くなったら一括追加やExcelを使うと分かりやすいです。

### キーボードで素早く入力する

追加・編集画面と左側のタグパネルでは、**Tabキー** で入力欄を上から順番に移動できます。  
ID欄を含め、画面上の項目を上から順番にTabキーで移動し、最後は **［保存］** ボタンへ到達します。保存の次は一番上のID欄へ戻ります。

```text
入力欄1 → Tab → 入力欄2 → Tab → … → 保存 → Tab → 入力欄1
```

メイン画面のタブ切り替えは次のショートカットです。

```text
Ctrl + PageUp     前のタブ
Ctrl + PageDown   次のタブ
```

## 対応形式

### `.kvbd`

このツールの標準形式です。

Karaoke Video DataBaseとして、今後追加される独自拡張情報も保持できます。

### `.ylexa`

ゆかりスター互換形式として読み込み・保存できます。

独自追加テーブルを含んだ状態でも `.ylexa` へ保存できますが、そのファイルをゆかりスターで読み込み、ゆかりスター側から再エクスポートすると、ゆかりスターが認識しない独自情報は失われます。

- Excel取り込みエラー一覧を追加し、既存IDのエラーは該当レコードの個別編集画面へ移動可能
- Excel取り込み結果に「差分なし（更新せず）」件数を表示
- 差分が0件なら一覧タブの再読込も行わず、そのまま終了
- Excelエラー一覧に不正な列名と入力値を表示
- `.ylexa`でKVDB独自テーブルが無い場合もExcel書き出し自体は可能に改善
- Excel表紙の案内を`.kvbd`と差分再取り込み運用に更新
