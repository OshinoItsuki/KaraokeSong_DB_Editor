# 楽曲情報DBエディタ

楽曲情報データベースを編集するためのWindows向けツールです。

標準形式として **Karaoke Video DataBase (`.kvbd`)** を使用します。  
ゆかりスターの `.ylexa` 形式にも対応しており、既存DBの読み込みや互換形式での保存が可能です。

## 主な機能

- `.kvbd` / `.ylexa` の読み込み
- 曲・人物・タイアップ・シリーズ・タグ・メーカーなどの編集
- 歌手・作詞・作曲・編曲・タグなどの関連情報編集
- 複数データの一括追加・一括書き込み
- ふりがなの自動生成・修復
- Excelへの書き出し／取り込み
- 新規楽曲情報DBの作成
- DB整合性チェック
- GitHub Releasesを利用した最新版確認
- `.ylexa`互換出力

## ダウンロード

最新版はGitHubの **Releases** からダウンロードしてください。

配布ファイルの `楽曲情報DBエディタ.exe` を起動するだけで使用できます。

## 使い方

詳しい操作方法は、同梱の **`使い方.html`** を参照してください。

## 対応形式

### `.kvbd`

このツールの標準形式です。

Karaoke Video DataBaseとして、今後追加される独自拡張情報も保持できます。

### `.ylexa`

ゆかりスター互換形式として読み込み・保存できます。

独自追加テーブルを含んだ状態でも `.ylexa` へ保存できますが、そのファイルをゆかりスターで読み込み、ゆかりスター側から再エクスポートすると、ゆかりスターが認識しない独自情報は失われます。

## 動作環境

- Windows 11 推奨

## 更新

ツールの［ヘルプ］→［更新を確認...］から最新版を確認できます。

初期設定では起動時にもGitHub Releasesを確認し、新しいバージョンがある場合に通知します。  
起動時の確認は設定画面から無効にできます。
